# Screenshots

Screen captures and annotated images documenting the application's
visual output across different features.

## Directory Structure

| Directory          | Purpose                                          |
|--------------------|--------------------------------------------------|
| `gui/`             | Screenshots of the VisionMoCap Studio GUI        |
| `pose_detection/`  | Live skeleton overlay on camera footage          |
| `blender/`         | Exported animations playing inside Blender       |
| `exports/`         | Rendered output files (BVH, FBX, GLTF previews) |
| `development/`     | Work-in-progress captures during development     |

## Naming Conventions

- `gui_main_window.png`
- `pose_overlay_<subject>.png`
- `blender_<rig_name>_<pose>.png`
- All screenshots should be PNG format for lossless quality.
