# Tools

Standalone utility programs and helper applications used alongside
the main VisionMoCap project.

## What Belongs Here

- Blender add-ons for import/export
- Web-based preview tools
- Calibration utilities
- Data conversion tools
- Benchmarking harnesses

## Naming Conventions

- Each tool should live in its own subdirectory with a descriptive name.
- Include a `README.md` inside each tool directory explaining usage.
