# Presentation

Slides, figures, and videos prepared for project presentations,
reviews, or public demos.

## Directory Structure

| Directory   | Purpose                                        |
|-------------|------------------------------------------------|
| `slides/`   | Slide decks (PowerPoint, PDF, or Markdown)     |
| `figures/`  | Standalone charts, plots, and infographics     |
| `videos/`   | Pre-rendered presentation videos               |

## Naming Conventions

- Slides: `presentation_<milestone>_<date>.<ext>`
- Figures: `fig_<topic>.<ext>`
- Videos: `presentation_<milestone>_<date>.<ext>`
