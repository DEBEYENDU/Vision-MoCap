# Demo

Demonstration assets used to showcase the project to stakeholders,
in presentations, or for testing.

## Directory Structure

| Directory             | Purpose                                              |
|-----------------------|------------------------------------------------------|
| `videos/`             | Recorded demo videos (`.mp4`, `.mov`)                |
| `gifs/`               | Animated GIFs for quick visual reference             |
| `sample_recordings/`  | Pre-recorded JSON motion captures for testing        |
| `sample_exports/`     | Exported animation files (BVH, FBX, GLTF) for demos |

## Naming Conventions

- Videos: `demo_<feature>_<date>.<ext>` (e.g. `demo_pose_tracking_2026-07-09.mp4`)
- GIFs: `demo_<feature>.<ext>`
- Recordings: `demo_<description>.json`
- Exports: `demo_<rig>_<description>.<ext>`
