# Scripts

Utility scripts for development, automation, and maintenance tasks.

## What Belongs Here

- Database migrations
- Data processing scripts
- CI/CD pipeline helpers
- Environment setup scripts
- One-off analysis or migration tasks

## Naming Conventions

- `setup_dev_env.sh` / `setup_dev_env.ps1`
- `migrate_<description>.py`
- `export_<source>_to_<target>.py`
- Prefer `.py` for cross-platform scripts; use `.sh` or `.ps1` only for
  shell-specific operations.
