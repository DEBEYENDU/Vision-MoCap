# Report

Formal reports, final documentation, and academic submissions.

## Directory Structure

| Directory     | Purpose                                                  |
|---------------|----------------------------------------------------------|
| `chapters/`   | Individual report chapters / sections in Markdown or LaTeX |
| `images/`     | Diagrams, screenshots, and figures for the report        |
| `references/` | BibTeX, Zotero exports, or citation files                |
| `plagiarism/` | Plagiarism check reports and originality statements      |

## Naming Conventions

- Chapters: `chapter_<number>_<title>.md` (e.g. `chapter_01_introduction.md`)
- References: `references.bib` or `references.json`
- Plagiarism: `plagiarism_report_<date>.pdf`
